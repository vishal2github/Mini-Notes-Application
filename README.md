### Mini Notes

A simple desktop text editor built with **Python** and **Tkinter**.

### Features

- Open `.txt` files

- Save notes as text files

- Create a new note

- Confirmation before clearing the current note

- File menu with Open, Save, and Exit

- Save status message

- Custom application icon

- Dark-themed interface

### Project Structure

```
mini-notes-application/
│
├── images/
│   └── window-icon.png
│
├── .gitignore
├── README.md
├── main.py
├── gui.py
└── logic.py
```

- `main.py` — Application entry point

- `gui.py` — GUI and widget layout

- `logic.py` — Application actions and file operations

### Run

Make sure Python 3 and Tkinter are installed.

```
python main.py
```

### About

Mini Notes started as a single-file Tkinter application and was later reorganized into separate modules.

This is a learning project focused on understanding Tkinter, Python modules, event-driven programming, file handling, and basic application organization.
